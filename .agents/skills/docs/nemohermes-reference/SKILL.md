# NemoHermes Reference

NemoHermes is the Hermes Agent profile of NemoClaw (`NEMOCLAW_AGENT=hermes nemoclaw`). It manages Hermes Agent sandboxes with a web dashboard, OpenAI-compatible API, and managed gateway lifecycle.

## CLI Structure

```
nemohermes <global-command>         # Global operations (list, onboard, agents)
nemohermes <sandbox-name> <command>  # Sandbox-scoped operations
```
